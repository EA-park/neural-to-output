# neural-to-output

인간의 생체 전기 신호를 로봇 동작으로 변환하기 위한 오픈소스 프레임워크입니다.

## 개요

`neural-to-output`은 원시 생체 전기 신호(예: EEG, EMG)를 로봇 시스템을 구동하는
명령으로 변환하는 데 필요한 요소들을 제공합니다 — 신호 수집, 처리, 그리고 액추에이터
출력으로의 매핑까지 다룹니다.

프로젝트를 로컬에서 설정하려면 [Getting Started](getting-started/index.md)를,
파이프라인이 어떻게 구성되는지는 [Architecture](architecture.md)를 참고하세요.
