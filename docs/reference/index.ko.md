# Reference

`src/n2o/`의 독스트링과 소스 코드로부터 자동 생성됩니다 — 각 항목은 클래스/함수의 전체
모듈 경로와 실제 소스 코드를 함께 보여주므로, 그것이 정확히 어디에 있는지 항상 알 수
있습니다.

이 페이지는 개념 설명 페이지들([Signal](../signal/index.ko.md),
[Decoder](../decoder/index.ko.md), [Command](../command/index.ko.md),
[Robot](../robot/index.ko.md)) — 각 조각이 어떻게 맞물리는지 설명하는 곳 — 의
보완재입니다. 해당 페이지에서 클래스/함수 이름을 클릭하면 바로 이곳의 항목으로
이동합니다.

`n2o/` 아래의 트리는 `src/n2o/`의 폴더 구조를 패키지 단위로 그대로 반영합니다:

- [n2o.signal](n2o/signal/index.md) ([dataset](n2o/signal/dataset/index.md), [stream](n2o/signal/stream/index.md))
- [n2o.decoder](n2o/decoder/index.md) ([classification](n2o/decoder/classification/index.md), [regression](n2o/decoder/regression/index.md), [utils](n2o/decoder/utils/index.md))
- [n2o.command](n2o/command/index.md)
- [n2o.robot](n2o/robot/index.md) ([arm](n2o/robot/arm/index.md), [hand](n2o/robot/hand/index.md), [camera](n2o/robot/camera/index.md), [solver](n2o/robot/solver/index.md), [simulation](n2o/robot/simulation/index.md))
