# Tutorials

Step-by-step guides for common workflows. Where a tutorial has a matching runnable
notebook, it links to the corresponding numbered file under
[`examples/`](https://github.com/EA-park/neural-to-output/tree/main/examples) in the
repo. Most notebooks are self-contained (explanation and code live together in the
notebook itself), so not every one gets a page here — this section is for concepts
that need a longer write-up.
